# HoverCopy

[English version](README.md)

Копирует слово под курсором мыши по горячей клавише — в любом окне, в том числе там, где
текст нельзя выделить: в играх, на картинках и видео, в интерфейсах программ. Текст
распознаётся с экрана локально моделями PaddleOCR, ничего никуда не отправляется. Один
переносимый `HoverCopy.exe` (~28 МБ) для Windows 10/11, установка не нужна.

## Как пользоваться

1. Запустите `HoverCopy.exe` — он появится в трее.
2. Наведите курсор на слово и нажмите **F8**.
3. Слово уже в буфере обмена, а у курсора на секунду появится «Copied: …» (это можно
   отключить).

Копируется одно слово — без знаков препинания по краям (`«привет»,` → `привет`), но с теми,
что внутри (`1,250`, `mr.smith`, `user_42`). В китайском и японском, где нет пробелов, словом
считается текст между знаками препинания. Нажатие обрабатывается примерно за 0,25 с.

## Настройки

Значок в трее → **Settings…**: сочетание клавиш (Esc очищает поле), язык интерфейса,
надпись «Copied» (по умолчанию выключена) и снимки для отладки. Интерфейс по умолчанию
английский, русский выбирается там же в списке **Language**. Изменения применяются по
кнопке **Save** («Сохранить» в русском интерфейсе). Хранятся они в
`%APPDATA%\HoverCopy\settings.ini`; файл можно править и вручную (тогда — перезапустить
программу).

## Ограничения

- Распознаются латиница, цифры, знаки и китайский. Кириллица и корейский — нет: их нет в
  алфавите модели.
- Очень мелкий текст (около 11 px) на шумном фоне читается хуже.

## Сборка

Нужен [Rust](https://rustup.rs): на Windows — `build.bat` (нужны Visual Studio Build Tools
с компонентом «Desktop development with C++»), на Linux — кросс-сборка `./build.sh` (нужны
target `x86_64-pc-windows-gnu` и `gcc-mingw-w64-x86-64`). Результат — `dist/HoverCopy.exe`.

Тесты: `cargo test --profile fast -- --nocapture` выводит точность распознавания на тестовых
картинках с разными фонами, шрифтами и размерами (`tests/fixtures`, их делает
`tools/make_fixtures.py`).
